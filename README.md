# ✨ Monthly Habit Tracker ✨

A lightweight, minimal, and responsive web-based **Habit Tracker** designed to help you build and maintain your daily streaks. Built using pure HTML, CSS, and vanilla JavaScript.

---

## 🚀 Features

* **Dynamic Calendar Grid:** Automatically detects the current year and month, calculating the exact number of days to display dynamically.
* **Today Highlight:** Visually highlights the current calendar date with a custom border and accent color.
* **Customizable Habits:** Click on the habit header to quickly change the tracker's title via an interactive prompt.
* **Persistent Data Tracking:** Uses the browser's `localStorage` to save your habit name and logged days. Your data stays safe even if you refresh or close the tab!
* **Dynamic Progress Counter:** Automatically calculates your monthly completion ratio (e.g., `5/31`) as you log days.
* **Interactive Streaks:** Toggle day boxes between active (Plum) and inactive (White) states with a single click.
* **One-Click Reset:** A quick reset button to clear your progress and start fresh.

---

## 🛠️ Tech Stack

* **HTML5** - Structure and layout
* **CSS3** - Custom styling, flexbox layouts, and custom typography fonts
* **JavaScript (ES6+)** - Date logic, DOM manipulation, and browser data persistence
